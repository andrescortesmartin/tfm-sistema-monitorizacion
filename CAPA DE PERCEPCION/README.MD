# Capa de Percepción

Esta capa contiene el firmware y la configuración de los tres tipos de dispositivo físico del sistema: anclas LoRa, nodos sensores (loggers) y balizas móviles.

## Dispositivos

| Carpeta | Rol |
|---|---|
| `ANCLAS LORA` | Punto de referencia fijo del subsistema de posicionamiento |
| `NODOS SENSORES` | Logger animal: escaneo BLE, sensores lentos, movimiento, posicionamiento |
| `BALIZAS MOVILES` | Baliza BLE portada por animales |

Ver el README de cada carpeta para el detalle funcional específico de cada dispositivo
